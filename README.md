# Лабораторна робота № 1

**Розгортання середовища автоматизації тестування. Структура проєкту та перший автоматизований тест**

**Виконала:** Бабʼяк Марія Йосипівна
**Група:** ІПЗ-1, 4 курс
**Варіант:** 3 — перетворення секунд на рядок формату «гг:хх:сс»; відхилення відʼємних значень

## Структура проєкту

```
qa-automation/
├── src/
│   └── temperature.ts          # перетворення градусів Цельсія у Фаренгейта
├── tests/
│   └── temperature.test.ts     # тести для celsiusToFahrenheit
├── .gitignore                  # файли й каталоги, виключені з репозиторію
├── .prettierrc                 # правила форматування коду
├── eslint.config.mjs           # конфігурація лінтера ESLint
├── package.json                # опис проєкту, залежності та команди запуску
├── package-lock.json           # зафіксовані версії залежностей
├── tsconfig.json               # налаштування компілятора TypeScript
├── vitest.config.ts            # налаштування раннера тестів і покриття
└── README.md                   # опис проєкту
```

## Вимоги

- Node.js версії 20.x або новішої (роботу виконано на v24.14.0)
- npm (роботу виконано на 11.9.0)
- Git

## Встановлення

```bash
git clone <адреса репозиторію>
cd qa-automation
npm install
```

## Запуск

| Команда              | Призначення                                        |
|----------------------|----------------------------------------------------|
| `npm test`           | Одноразовий прогін усіх тестів                     |
| `npm run test:watch` | Режим спостереження: перезапуск при зміні файлів   |
| `npm run coverage`   | Прогін тестів із вимірюванням покриття             |
| `npm run lint`       | Статичний аналіз коду                              |
| `npm run format`     | Автоматичне форматування коду                      |

Після `npm run coverage` HTML-звіт про покриття буде у файлі `coverage/index.html`.
